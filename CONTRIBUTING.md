# Contributing

Contributions are welcome through issues and pull requests.

## Before opening a pull request

1. Do not add student, teacher, or family personal data.
2. Do not add raw policy documents without a source-level rights decision.
3. Add or update source URLs, retrieval dates, and content hashes for released claims.
4. Preserve uncertainty, abstention, human-review, correction, and retirement states.
5. Run `npm ci`, `npm test`, and `npm run build`.
6. Describe the affected claim IDs and attach failure cases for extraction changes.

By intentionally submitting a contribution, you agree that it is licensed under Apache-2.0.

## Review

The maintainer checks correctness, data rights, security boundaries, accessibility, and backward compatibility. A passing automated check does not replace human review of policy meaning.
